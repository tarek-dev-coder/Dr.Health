# Dr.Health

Dr.Health is a free health assistant with a dark-first, hand-built interface. Ask a question or attach a text file and get a clear answer. There is no account, no sign-in, no database, and no daily message quota. Chats can be saved in your browser.

> **Important:** Dr.Health gives you context, not a diagnosis. In an emergency, contact your local emergency number.

## What it does

- Ask health questions in plain language and get one clear answer
- Attach a text file (health notes, a symptom diary, or code) and have it read
- Example questions appear automatically when you start a new chat
- Chats are saved in your browser only — nothing is stored on a server
- Dark theme by default, light theme available
- No accounts, no sign-in, no cookies, no daily message cap
- Free to use

## Privacy and medical safety

- Dr.Health gives context, not a diagnosis, and does not replace professional medical care
- If you describe a possible emergency, the assistant directs you to local emergency services
- Chats stay in your browser until you clear them; anyone with access to your browser profile can read them
- Attached file text is not saved — only the file name appears in your saved chat history
- Do not enter identifying information or protected health information
