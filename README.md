## What I Do

| Feature | Detail |
|---|---|
| Health questions | Plain language, one clear answer |
| File attachments | Health notes, symptom diaries, code |
| Example prompts | Auto-generated per chat |
| Storage | Browser only (`localStorage`) — nothing on server |
| Theme | Dark by default, light available |
| Access | No sign-in, no cookies, no limits |

---

## 🤝 About

Ask a question and I'll use context from any optional text attachments you share. Replies are direct and brief.

Context only — not a diagnosis or a substitute for professional care. In an emergency, contact local services first.

---

## Privacy

- No server storage of prompts, replies, or file content
- Browser history (`localStorage`) — clear anytime
- Only filenames saved in chat history; file text never stored
- No identifying info required

---

## Process

```text
ask() → validate() → respond() → clear()
```

- **Ask** — send a health question or a file
- **Validate** — the text or file gets checked
- **Respond** — you get a direct, brief answer
- **Clear** — nothing stored server-side; clear your browser anytime
