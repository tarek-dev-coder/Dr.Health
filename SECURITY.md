## What We Protect

| Area | Status |
|---|---|
| Accounts / Sign-in | ❌ None required |
| Database / Server storage | ❌ None |
| Chat history | ✅ Browser (`localStorage`) only |
| File attachments | ✅ Filename only saved; text never stored |
| Provider credentials | ✅ Server-side only |
| Health data in reports | ❌ Never include real data |

---

## How to Report an Issue

> **Do not open a public issue.** Contact the maintainer privately through the repository profile. Include reproduction steps and affected version. **Never include real health or identifying data.**

---

## Policy

- Security fixes apply to the latest release on the default branch
- Older copies or forks do not receive backported fixes
- Redeploy from current code and rotate any previously exposed secrets
